    Add thumbnails in Google Drive

    Google Drive isn't connected on this copy of the site yet. Whoever runs it needs to fill in config.js; the steps are in the README under "Google Drive setup".

    Choose .ipv files in your Drive. Each one gets its finished artwork as its thumbnail, so you can see it in Drive's file grid.

    This site only gets access to the files you choose. Drive can take a few minutes to show new thumbnails. Uploading a new version of a file removes its thumbnail, so add it again afterwards. Privacy
